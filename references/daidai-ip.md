# daidai IP

## 角色定义

daidai 是本技能的固定视觉 IP。一个全彩年轻男程序员，认真做一件荒诞但成立的事。他不是吉祥物，不是贴纸，不是可爱装饰，而是正在参与系统运转的荒诞工作者。

生成时必须把已确认的三视图作为图像参考输入，不能只靠文字描述重画。根据版本选择对应的三视图：
- 标准版：`assets/standard/three-view.png`
- Q 版：`assets/chibi/three-view.png`

## 标准版外形

- 瘦高男性，约 7.5 头身，肩窄腰细，四肢修长。
- 黑色凌乱短发，刘海覆盖额头，头顶几缕碎发翘起，发尾及耳。
- 深棕色大眼，平静略带疏离，上眼睑有明显线条，瞳孔有高光点。
- 黑色直眉，粗细中等，眉尾略下垂。
- 小嘴，薄唇，默认闭合呈短直线。
- 鹅蛋脸偏瘦，下巴略尖。

## Q 版外形

- 头大身小，约 2.5 头身比例，身体短圆，四肢短小。
- 超大圆眼睛，占据脸部约 1/3，深棕色瞳孔有明显高光，眼神认真呆萌。
- 圆润的脸型，下巴圆钝，小巧的鼻子和嘴巴。
- 黑色蓬松短发，刘海覆盖额头，头顶几缕碎发翘起，发量感更强更圆润。
- 黑色直眉，略粗，眉尾略下垂，表情略带认真/呆萌。
- 整体感觉可爱但不幼稚，保留程序员的认真气质。

### 服装（两版通用）

- 蓝灰紫色竖条纹宽松衬衫，领口敞开露出黑色圆领内搭 T 恤。
- 袖子卷至小臂中部，袖口翻边。
- 深炭灰色宽松阔腿西裤，腰部有褶裥，裤腿宽大垂坠，长度盖鞋面。
- 黑色简约圆头皮鞋，低帮，无明显装饰。

### 固定配饰

- **黑色细绳 choker + 极小不规则绿松石吊坠**：紧贴颈部，位于锁骨上方，衬衫领口敞开时可见。吊坠很小、形状不规则非对称。绿松石是画面中唯一的蓝绿色小块。
- **右手腕细红色手链**：画面中唯一的红色角色配饰，与红色批注颜色呼应。

### 条件配饰

- **黑色挂绳工牌**：黑色卡套 + 白色内卡，内卡上若隐若现写着"daidai"（手写体，模糊低对比度）。
  - 工作场景（技术博客、项目讲解、科普、工作流、代码相关）：佩戴。
  - 非工作场景（生活、随笔、感悟）：不佩戴。

## 性格

- 很认真，但做的事有点荒诞。
- 像一个低调的程序员/系统操作员。
- 冷幽默，不卖萌。
- 有点笨拙，但不蠢。
- 像在白纸草图里真的负责某个工作。

## 常见职责

让 daidai 承担核心动作：

- 把 bug 塞进粉碎机
- 卡在代码机器里拉判断杆
- 用漏斗筛选需求
- 牵着部署路径的线
- 举警告牌看线上事故
- 把需求文档压成面条
- 在抽屉里翻找丢失的上下文
- 给 API 打电话
- 搬砖搭技术栈
- 蹲在机器旁边拧螺栓修生产环境
- 从井里打捞丢失的数据
- 把灵感塞进发布管道
- 站在白板前梳理混乱的思路

## 禁止

- 标准版：不要把 daidai 画成过度可爱的吉祥物。Q 版除外，Q 版本身就是可爱风格。
- 不要画成儿童卡通角色（Q 版是 chibi 比例，不是儿童）。
- 不要给 daidai 复杂表情包、闪亮眼睛（Q 版可以有大眼睛高光，但不要星星眼/闪光特效）。
- 不要让 daidai 只是站在角落里看。
- 不要让 daidai 抢走结构表达。
- 不要改变发型、服装、配饰等身份锚点。
- 不要把 daidai 画成黑白线稿（他必须全彩）。
- 不要改变他的服装颜色（蓝灰紫衬衫、黑内搭、炭灰裤）。
- 不要在标准版和 Q 版之间混用比例（要么 7.5 头身，要么 2.5 头身，不要中间态）。

## 判断标准

如果去掉 daidai，图的核心隐喻还能完全成立，说明 daidai 太装饰了；要重写提示词，让 daidai 成为动作主体。
